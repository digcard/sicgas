Funciona em Mac ou Linux?
Não, o SICGAS é desenvolvido exclusivamente para Windows 10 e Windows 11. Esses sistemas representam mais de 95% dos computadores usados por entregadores no Brasil.
Preciso pagar algo?
Não para os 100 primeiros usuários! A versão gratuita oferece 30 execuções completas, suficientes para você comprovar os resultados. Após isso, há planos acessíveis a partir de R$ 29,90/mês.
Como registro minha planilha Google?
O SICGAS mostra um tutorial passo a passo quando você abre pela primeira vez. Em resumo: 1) Crie uma planilha no Google Sheets, 2) Compartilhe com o e-mail que o programa fornece, 3) Cole o link no SICGAS. Todo o processo leva menos de 3 minutos.
